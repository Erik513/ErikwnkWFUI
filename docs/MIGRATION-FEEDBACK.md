# Findings of the project migrations

The chats that move a project to the new ErikwnkWFUI (see `MIGRATE-A-PROJECT.md`) write here what is wrong,
missing or surprising **in the library**: one bullet each - what, where (file:line in the project), what
would help. The chat of the library reads this file afterwards, fixes the library and updates
`MIGRATION.md` and `CHANGELOG.md`; fixed items are marked `(done)`.
